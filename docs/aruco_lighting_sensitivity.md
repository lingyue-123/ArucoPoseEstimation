# 光照对 ArUco 位姿估计的影响

## 1. 问题概述

**现象**：可视化窗口中 ArUco 四个角点的像素位置未见明显变化，但光照变化导致位姿估计出现约 2mm 偏差。

**根因**：亚像素角点漂移（0.1~0.5 px）→ PnP 求解器在 Z（深度）方向将误差放大 5~10 倍 → 产生 mm 级位姿偏差。可视化用整数像素绘制角点，掩盖了亚像素级漂移。

---

## 2. PnP 误差放大原理

### 2.1 Z 方向灵敏度极低

PnP 用 4 个角点的图像坐标求解 6-DOF 位姿。不同自由度的运动在图像上产生的像素位移差异巨大。

**参数设定**（本工程典型值）：

| 参数 | 值 |
|------|-----|
| marker 边长 | 15 mm |
| 工作距离 Z | ~300 mm |
| 焦距 f_x | ~2000 px |

**灵敏度对比**：

```
X 平移 1mm → 角点移动  f_x / Z     = 2000 / 300      ≈ 6.67 px    (非常敏感)
Z 平移 1mm → 角点移动  f_x·X / Z²  = 2000×7.5 / 90000 ≈ 0.17 px    (极不敏感)

灵敏度比值:  6.67 / 0.17 ≈ 40 倍
```

| 运动方向 | 1mm 运动产生像素位移 | 1px 角点误差导致位姿误差 |
|---------|:---:|:---:|
| X 平移 | 6.67 px | 0.15 mm |
| Y 平移 | 6.67 px | 0.15 mm |
| Z 平移 | **0.17 px** | **6.0 mm** |

Z 平移 1mm 在图像上仅产生约 0.17 像素的变化，和亚像素噪声（0.1~0.5 px）处于同一数量级。反解时，PnP 需要从噪声中辨识 Z 信号，不可避免地放大误差。

### 2.2 条件数与 Jacobian 奇异值

PnP 的 Jacobian 矩阵 J (8×6) 将位姿变化映射为像素变化：

```
δu = J · δθ       (8×1 = 8×6 · 6×1)
```

反解位姿变化：

```
δθ = J⁺ · δu      (6×1 = 6×8 · 8×1)
```

其中 J⁺ 是 J 的伪逆。对 J 做 SVD 分解 `J = U · Σ · V^T`，则 `J⁺ = V · Σ⁺ · U^T`。

J 的 6 个奇异值对应 6 个自由度的可观测性（示意值）：

```
σ1 = 13.3   (X 平移, 信号最强)
σ2 = 13.3   (Y 平移, 信号最强)
σ3 = 5.0    (某旋转)
σ4 = 3.0    (某旋转)
σ5 = 2.0    (某旋转)
σ6 = 0.3    (Z 平移, 信号最弱)  ← 最小奇异值
```

J⁺ 的奇异值是 J 奇异值的**倒数**：

```
1/σ1 = 0.075
1/σ2 = 0.075
1/σ3 = 0.20
1/σ4 = 0.33
1/σ5 = 0.50
1/σ6 = 3.3   ← 放大 11 倍

条件数 = σ_max / σ_min = 13.3 / 0.3 ≈ 44
```

δu 在 U 的第 6 列方向上的分量（对应 Z 的信号子空间）会被放大 11 倍映射到 δθ。

### 2.3 为什么 Z 是最不可观测量

不同自由度的运动在图像上产生不同的"角点位移模式"：

```
X 平移:   ■ → ■           4个角点同向水平移动，位移大，模式鲜明
Y 平移:   ■ → ■           4个角点同向垂直移动，位移大，模式鲜明
X/Y旋转:  ■ ⟍             梯形变形，角点位移有差异，模式可辨析
Z 旋转:     ■              角点绕中心旋转，位移中等
          ↙  ↘

Z 平移:   □ → □           4个角点向中心收缩/向外扩张
          收缩/扩张         每个角点位移量极小且沿径向
                           模式与随机角点噪声高度相似！
```

Z 平移让角点做缩放运动，每个角点的位移量极小（~0.17 px/mm）。当角点存在 ±0.3 px 随机噪声时，PnP 无法可靠区分"Z 移动了 1.8mm"还是"角点噪声"，倾向于把无法解释的残差扔到 Z 上——这就是放大效应的本质。

## 3. 亚像素角点漂移

### 3.1 cornerSubPix 梯度鞍点原理

`cornerSubPix` 基于**梯度鞍点假设**：角点是邻域内所有梯度向量指向/背离的唯一点。对于窗口内每个像素 q，梯度 ∇I(q) 应满足：

```
∇I(q) · (p* - q) = 0
```

即梯度方向应与"该像素指向角点"的向量正交。所有窗口内像素构成超定方程组，用最小二乘求解 p*：

```
(Σ ∇I·∇I^T) · p* = Σ (∇I·∇I^T) · q

其中 Σ ∇I·∇I^T 是 2×2 Hessian 矩阵:
  [ Σ I_x²      Σ I_x·I_y  ]
  [ Σ I_x·I_y   Σ I_y²     ]
```

这个 Hessian 矩阵编码了邻域内梯度的方向分布和强度。它的"重心"决定了 p* 的位置。

### 3.2 光照如何破坏梯度对称性

```
均匀光照（梯度对称）                 不均匀光照（梯度不对称）

    ↗  ↘                                  ↗   ↘         ← 强光侧梯度大
   ↗    ↘                                ↗     ↘
  ●  ←  ●        鞍点在几何中心         ●  ←    ●        ← 弱光侧梯度小
   ↘    ↗                                ↘       ↗
    ↘  ↗                                  ↘     ↗
                                            ↘  ↗
                                             ●  ← 鞍点漂移
```

在 Hessian 矩阵中，梯度大的像素（强光侧）权重大，梯度小的像素（弱光侧）权重小。最小二乘解被"拉"向弱光侧，导致亚像素角点偏离真实几何位置。

代码中的关键参数（`robovision/detection/aruco.py:357-361`）：

- `winSize=(5, 5)`：仅 25 个梯度样本，局部光照异常极易主导结果
- 迭代 30 次，终止精度 0.001 px

### 3.3 预处理对光照敏感性的影响

| 预处理步骤 | 位置 | 对光照敏感性的影响 |
|-----------|------|------------------|
| CLAHE (`clipLimit=2.0`) | `aruco.py:233` | **放大**局部对比度差异 → 梯度不对称更严重 |
| GaussianBlur (3×3) | `aruco.py:234,333` | 轻微平均化梯度 → 轻微缓解 |
| MORPH_OPEN + MORPH_CLOSE (3×3) | `aruco.py:236-237` | 修改 marker 边界微结构 → 影响不确定 |
| OpenCV 内部自适应二值化 | `aruco.py:213-215` | 局部均值阈值 → 光照变化平移二值化边界 |

## 4. 为什么时域滤波（Kalman / EMA）无法消除

### 4.1 随机噪声 vs 系统性偏置

```
帧 1: 光照均匀 → 角点偏移 [+0.2, +0.1, -0.1, -0.2] → PnP → Z = 301.2mm
帧 2: 光照均匀 → 角点偏移 [+0.2, +0.1, -0.1, -0.2] → PnP → Z = 301.2mm
帧 3: 光照均匀 → 角点偏移 [+0.2, +0.1, -0.1, -0.2] → PnP → Z = 301.2mm
       ↑ Kalman 将此偏置视为"真实值"，误差不会收敛到 0

--- 光照变化 ---

帧 4: 侧光射入 → 角点偏移 [+0.4, +0.2, -0.1, -0.3] → PnP → Z = 301.8mm
帧 5: 侧光射入 → 角点偏移 [+0.4, +0.2, -0.1, -0.3] → PnP → Z = 301.8mm
       ↑ EMA(α=0.4) 平滑地从 301.2 过渡到 301.8，但不会"纠正"这个偏置
```

| 误差类型 | 特征 | Kalman 能滤？ | EMA 能滤？ |
|---------|------|:---:|:---:|
| 传感器热噪声 | 零均值、随机 | 能 | 能 |
| 光照导致的亚像素偏置 | 非零均值、方向与光照相关 | **否**，会跟踪偏置 | **否**，会平滑但不消除 |

### 4.2 偏置跟随光照变化

光照偏置不是固定值，而是随光照条件实时变化的系统误差。Kalman 和 EMA 平滑器只会跟踪这个变化的偏置，不会消除它。它们的设计目标是抑制高频噪声，对低频系统偏置无能为力。

## 5. 可视化为什么看不出

`robovision/visualization/aruco_overlay.py:58`：

```python
corners = data['filtered_corners'].astype(int)
cv2.circle(vis, (cx, cy), CORNER_RADIUS, (0, 255, 0), -1)
```

角点坐标 `.astype(int)` 将浮点小数直接截断。实际参与 PnP 计算的是 `np.float64` 类型（`aruco.py:362`），精度到小数点后 6 位。0.3 px 的亚像素漂移在整数绘制时不可见，但在 PnP 中会被放大为 mm 级位姿误差。

验证方法：在 `aruco.py:362` 后打印角点坐标：

```python
logger.info(f"ID{marker_id} corners:\n"
            f"  C0: ({refined_corners[0,0]:.6f}, {refined_corners[0,1]:.6f})\n"
            f"  C1: ({refined_corners[1,0]:.6f}, {refined_corners[1,1]:.6f})\n"
            f"  C2: ({refined_corners[2,0]:.6f}, {refined_corners[2,1]:.6f})\n"
            f"  C3: ({refined_corners[3,0]:.6f}, {refined_corners[3,1]:.6f})")
```

对比光照变化前后的浮点坐标即可验证。

## 6. 缓解方案

按优先级从高到低排列：

### 6.1 增大 cornerSubPix 窗口大小

**影响**：高 | **风险**：低 | **改动量**：3 行

- `aruco.py:210`：`cornerRefinementWinSize` 从 5 改为 11
- `aruco.py:359`：`winSize` 从 `(5,5)` 改为 `(11,11)`
- `aruco.py:72`：`detect_raw_frame` 中的 `cornerSubPix` 同步改为 `(11,11)`

原理：窗口从 5×5（25 个梯度样本）扩大到 11×11（121 个样本），光照不均匀造成的单侧梯度优势被平均化，漂移可降低 40%~60%。

### 6.2 改用 CORNER_REFINE_CONTOUR

**影响**：高 | **风险**：中 | **改动量**：1 行

`aruco.py:209`：`cornerRefinementMethod` 从 `CORNER_REFINE_SUBPIX` 改为 `CORNER_REFINE_CONTOUR`

原理：`SUBPIX` 在原始灰度梯度上找鞍点 → 对光照敏感。`CONTOUR` 先提取二值化边界轮廓，拟合直线求交点作为角点 → 不依赖灰度梯度对称性，对侧光/阴影容忍度高。

注意：如果 marker 边界模糊导致轮廓提取不准确，精度可能反而不如 SUBPIX。建议与 6.1 二选一。

### 6.3 启用深度图融合（SVD 刚体配准）

**影响**：最高 | **风险**：低 | **改动量**：调用侧 1 行

代码已完全实现（`depth_pose.py:135-193`），调用时传入 `depth_map`：

```python
# 纯 PnP（当前）
result = detector.detect(frame)

# 深度融合（需要深度相机）
result = detector.detect(frame, depth_map=depth_image)
```

原理：从深度图反投影角点为 3D 点 → SVD 刚体配准 → Z 精度由深度传感器决定，不再受 PnP 的 Jacobian 放大效应影响。**这是唯一从根源上绕过 Z 放大效应的方案**，但需要深度相机（如 Orbbec Gemini 335LG）。

### 6.4 降低 CLAHE 激进程度

**影响**：中低 | **风险**：低 | **改动量**：2 行

- `aruco.py:155`：`clipLimit` 从 2.0 改为 1.0
- `aruco.py:55`：`detect_raw_frame` 中的 CLAHE 同步改为 1.0

原理：`clipLimit` 控制对比度放大上限，2.0 → 1.0 意味着少放大 50% 局部对比度，光照变化引起的梯度不对称性减弱。代价是极暗环境下检测率可能降低。

### 6.5 硬件：均匀补光 + 偏振片

**影响**：最高 | **风险**：无 | **改动量**：0 行

- 环形 LED 从相机光轴方向补光 → 消除单侧阴影
- 偏振片贴光源和镜头前 → 消除 marker 表面镜面反射（黑白块光泽差异是梯度不对称的物理根源）

这是从根本上消除造成梯度不对称的物理条件，推荐作为长期稳定方案。
